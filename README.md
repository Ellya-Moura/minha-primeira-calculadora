# 📊 Minha Primeira Calculadora Contábil

Este é o meu primeiro algoritmo desenvolvido em **Python**, criado com o auxílio de Inteligência Artificial para fins de estudo de lógica de programação.

## 🧮 O que o programa faz?
O sistema simula o cálculo financeiro básico de uma microempresa enquadrada no Simples Nacional:
* Recebe o faturamento bruto e os custos operacionais.
* Calcula automaticamente o imposto simulado (taxa de 6%).
* Exibe o lucro líquido final formatado em Reais (R$).

## 🛠️ Tecnologias Utilizadas
* **Python** para a lógica do algoritmo.
* **GitHub** para o controle de versão e armazenamento em nuvem.
